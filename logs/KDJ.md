# KDJ 特征设计

## 结论

KDJ 在本项目中应主要作为**近期价格区间位置**与**短期动量**的连续特征，而不是机械使用传统金叉、死叉交易规则。

第一版建议优先保留 `K` 及其变化量；`D` 与 `J` 可作为后续验证的补充。

| 特征              | 角色                        | 是否建议首版输入模型 |
| ----------------- | --------------------------- | -------------------- |
| `kdj_k`           | 平滑后的区间位置 / 动量状态 | 是                   |
| `kdj_k_change_3d` | 短期动量变化                | 是                   |
| `kdj_d`           | `K` 的慢速平滑版本          | 否，后续验证         |
| `kdj_j`           | 放大 `K-D` 差异的敏感信号   | 否，后续验证         |

---

## KDJ 的核心思想

KDJ 本质上是在衡量：

> 当前收盘价位于最近一段时间价格区间中的什么位置。

它不是直接衡量绝对涨跌幅，而是将价格映射到近期 `high-low` 区间中，因此天然具有一定的归一化能力，适合跨股票比较。

---

## RSV：KDJ 的原始信号

定义：

$$
RSV_t = \frac{Close_t - Low_n}{High_n - Low_n} \times 100
$$

其中：

- `Low_n`：过去 `n` 日最低价；
- `High_n`：过去 `n` 日最高价；
- `Close_t`：当前收盘价。

典型解释：

| `RSV` | 含义                   |
| ----: | ---------------------- |
|   `0` | 收盘价位于近期区间底部 |
| `100` | 收盘价位于近期区间顶部 |
|  `50` | 收盘价位于近期区间中部 |

RSV 是 KDJ 最原始的信息来源，但对短期价格波动较敏感，因此噪声较大。

---

## `K`：对 RSV 做第一次平滑

当前实现采用平滑递推方式计算。

当 `m1 = 3` 时：

$$
K_t = \frac{2}{3}K_{t-1} + \frac{1}{3}RSV_t
$$

因此：

> `K` 是平滑后的近期价格区间位置。

相比 RSV，`K` 可以保留动量趋势，同时过滤部分短期噪音。对于机器学习特征而言，`K` 是 KDJ 中最核心、最直接值得保留的变量。

---

## `D`：对 K 再做一次平滑

定义：

当 `m2 = 3` 时：

$$
D_t = \frac{2}{3}D_{t-1} + \frac{1}{3}K_t
$$

信号速度从快到慢依次为 `J`、`K`、`D`。

`D` 本质上是 `K` 的慢速版本。传统 KDJ 中，`K` 上穿 `D` 为金叉，`K` 下穿 `D` 为死叉。

但从 ML 特征设计角度，单独加入 `D` 可能与 `K` 存在较强冗余：

$$
D = smooth(K)
$$

---

## `J`：放大 K 与 D 的差异

定义：

$$
J = 3K - 2D
$$

也可以写为：

$$
J = K + 2(K-D)
$$

因此，`J` 的本质是：

> 在 `K` 的基础上，进一步放大 `K-D` 的动量差。

`J` 比 `K`、`D` 更敏感：

- 优点：更早反映动量变化；
- 缺点：同时会放大噪音；
- `J` 可以超过 `100`，也可以低于 `0`。

从建模角度看，`J` 并不是完全独立的信息，因为它可以由 `K` 和 `D` 线性计算得到。

---

## 参数含义

当前默认参数为 `n=9`、`m1=3`、`m2=3`。

这是经典 KDJ 参数组合。

### `n`

`n` 控制 RSV 的观察窗口。

### `m1`

`m1` 控制 RSV 到 `K` 的平滑程度。`m1` 越大，`K` 越平滑、反应越慢。

### `m2`

`m2` 控制 `K` 到 `D` 的平滑程度。`m2` 越大，`D` 越平滑、反应越慢。

---

## 缺失值与除零处理

### Warm-up period

前 `n - 1` 行因滚动窗口尚未形成，`high_n` 与 `low_n` 为 `NaN`，RSV、`K`、`D`、`J` 应继续保留 `NaN`，不要人为填入 `50`。

### 区间宽度为零

当最近 `n` 天最高价和最低价完全相同时，区间宽度为零。

RSV 无法正常计算，此时应保留缺失值，而不是强行解释为超买或超卖。


计算有效性掩码时，还应排除尚未形成窗口的缺失值。

这样可以清楚地区分：

| 值 / 状态        | 含义                       |
| ---------------- | -------------------------- |
| `NaN`            | 历史数据不足，指标尚未定义 |
| `RSV = 50`       | 有效窗口内价格区间宽度为零 |
| `RSV` 位于 0–100 | 正常计算得到的区间位置     |

## 特征筛选建议

不建议因为传统 KDJ 包含 `K`、`D`、`J`，就机械地全部输入模型。三者存在明显数学相关性：

$$
D = smooth(K)
$$

$$
J = K + 2(K-D)
$$

### 保留 `kdj_k`

`kdj_k` 已经表达：

> 当前价格在近期价格区间中的平滑位置 / 动量状态。

它是首版最值得保留的 KDJ 核心信息。

### 加入 K 的变化量

可加入 `K` 的变化量，用于补充短期变化速度。

它可区分相同 `K` 水平下的加速与减速状态。

例如，两个相同 `K` 水平的样本可能分别对应上升与下降的短期动量。

### 优先测试 `K-D spread`，而非单独的 `D`

若后续决定计算 `D`，更值得测试的是 `K-D spread`，即快慢动量之间的偏离。

它直接描述：

> 快速动量相对于慢速动量的强弱。

传统金叉、死叉可以由 `K-D spread` 的符号穿越表达，但将连续信号离散为 0/1 会丢失偏离幅度、变化速度及持续性等信息。因此，连续的 `kdj_spread` 通常比金叉、死叉特征更值得优先验证。

---

## 推荐开发顺序

### 第一阶段

仅保留 `K` 与其短期变化量。

首先在 walk-forward 样本外验证其增量价值。

### 第二阶段

若特征重要度、SHAP 或 ablation test 显示 KDJ 有稳定贡献，再测试 `K-D spread` 和更长周期的变化量。

其中，`kdj_spread` 表示快慢动量差，`kdj_k_change_5d` 则补充相对更长一点的动量变化尺度。

### 第三阶段

再考虑明显不同的多窗口参数。

每增加一组特征，都应通过样本外 ablation test 验证其增量价值，避免无差别扩充高度相关的技术指标。

## 常见解读与阈值

下表的区间与事件用于描述指标状态，是研究参照而非独立的交易指令。

| KDJ 区间或事件 | 常见解读 |
| --- | --- |
| `K`、`D` 高于 80 | 价格位于近期区间上部，可能处于强势或超买状态。 |
| `K`、`D` 低于 20 | 价格位于近期区间下部，可能处于弱势或超卖状态。 |
| `K` 上穿 `D` | 短期位置动量可能转强。 |
| `K` 下穿 `D` | 短期位置动量可能转弱。 |
| `K`、`D` 位于 20–80 | 价格位于近期区间的中部，单独的方向信息通常较弱。 |
| `J` 明显高于 100 或低于 0 | 动量偏离可能很强，但也更易包含短期噪声。 |

极端区可在强趋势中持续存在，交叉和阈值应结合趋势状态验证。
