# KDJ 特征设计

## 结论

KDJ 在本项目中应主要作为**近期价格区间位置**与**短期动量**的连续特征，而不是机械使用传统金叉、死叉交易规则。

第一版建议仅保留：

```python
result["kdj_k"] = k
```

| 特征              | 角色                        | 是否建议首版输入模型 |
| ----------------- | --------------------------- | -------------------- |
| `kdj_k`           | 平滑后的区间位置 / 动量状态 | 是                   |
| `kdj_k_change_3d` | 短期动量变化                | 是                   |
| `kdj_d`           | `K` 的慢速平滑版本          | 否，后续验证         |
| `kdj_j`           | 放大 `K-D` 差异的敏感信号   | 否，后续验证         |

---

## KDJ 的核心思想

KDJ 本质上是在衡量：

> 当前收盘价位于最近一段时间价格区间中的什么位置。

它不是直接衡量绝对涨跌幅，而是将价格映射到近期 `high-low` 区间中，因此天然具有一定的归一化能力，适合跨股票比较。

```text
Price
  ↓
RSV：价格在近期区间中的位置
  ↓ 平滑
K：平滑后的区间位置 / 动量
  ↓ 再平滑
D：更慢的动量
  ↓
J：放大 K-D 差异的敏感信号
```

---

## RSV：KDJ 的原始信号

定义：

$$
RSV_t = \frac{Close_t - Low_n}{High_n - Low_n} \times 100
$$

其中：

- `Low_n`：过去 `n` 日最低价；
- `High_n`：过去 `n` 日最高价；
- `Close_t`：当前收盘价。

典型解释：

| `RSV` | 含义                   |
| ----: | ---------------------- |
|   `0` | 收盘价位于近期区间底部 |
| `100` | 收盘价位于近期区间顶部 |
|  `50` | 收盘价位于近期区间中部 |

RSV 是 KDJ 最原始的信息来源，但对短期价格波动较敏感，因此噪声较大。

---

## `K`：对 RSV 做第一次平滑

当前实现：

```python
k = rsv.ewm(alpha=1 / m1, adjust=False).mean()
```

当 `m1 = 3` 时：

$$
K_t = \frac{2}{3}K_{t-1} + \frac{1}{3}RSV_t
$$

因此：

> `K` 是平滑后的近期价格区间位置。

相比 RSV，`K` 可以保留动量趋势，同时过滤部分短期噪音。对于机器学习特征而言，`K` 是 KDJ 中最核心、最直接值得保留的变量。

---

## `D`：对 K 再做一次平滑

定义：

```python
d = k.ewm(alpha=1 / m2, adjust=False).mean()
```

当 `m2 = 3` 时：

$$
D_t = \frac{2}{3}D_{t-1} + \frac{1}{3}K_t
$$

信号速度关系为：

```text
RSV → K → D
最快       最慢
```

`D` 本质上是 `K` 的慢速版本。传统 KDJ 中，`K` 上穿 `D` 为金叉，`K` 下穿 `D` 为死叉。

但从 ML 特征设计角度，单独加入 `D` 可能与 `K` 存在较强冗余：

$$
D = smooth(K)
$$

---

## `J`：放大 K 与 D 的差异

定义：

$$
J = 3K - 2D
$$

也可以写为：

$$
J = K + 2(K-D)
$$

因此，`J` 的本质是：

> 在 `K` 的基础上，进一步放大 `K-D` 的动量差。

`J` 比 `K`、`D` 更敏感：

- 优点：更早反映动量变化；
- 缺点：同时会放大噪音；
- `J` 可以超过 `100`，也可以低于 `0`。

从建模角度看，`J` 并不是完全独立的信息，因为它可以由 `K` 和 `D` 线性计算得到。

---

## 参数含义

当前默认参数：

```python
n = 9
m1 = 3
m2 = 3
```

这是经典 KDJ 参数组合。

### `n`

`n` 控制 RSV 的观察窗口：

```text
n 越小 → 更敏感、更短期、噪音更大
n 越大 → 更平滑、更偏中期
```

### `m1`

`m1` 控制 RSV 到 `K` 的平滑程度。`m1` 越大，`K` 越平滑、反应越慢。

### `m2`

`m2` 控制 `K` 到 `D` 的平滑程度。`m2` 越大，`D` 越平滑、反应越慢。

---

## 缺失值与除零处理

### Warm-up period

前 `n - 1` 行因滚动窗口尚未形成，`high_n` 与 `low_n` 为 `NaN`，RSV、`K`、`D`、`J` 应继续保留 `NaN`，不要人为填入 `50`。

### 区间宽度为零

当最近 `n` 天最高价和最低价完全相同时：

```text
high_n == low_n
```

RSV 无法正常计算。此时设置：

```python
RSV = 50
```

表示价格处于中性状态，是合理的处理方式。

`mask` 应同时排除尚未形成窗口的缺失值：

```python
mask = denominator.notna() & (denominator != 0)
```

这样可以清楚地区分：

| 值 / 状态        | 含义                       |
| ---------------- | -------------------------- |
| `NaN`            | 历史数据不足，指标尚未定义 |
| `RSV = 50`       | 有效窗口内价格区间宽度为零 |
| `RSV` 位于 0–100 | 正常计算得到的区间位置     |

## 特征筛选建议

不建议因为传统 KDJ 包含 `K`、`D`、`J`，就机械地全部输入模型。三者存在明显数学相关性：

$$
D = smooth(K)
$$

$$
J = K + 2(K-D)
$$

### 保留 `kdj_k`

`kdj_k` 已经表达：

> 当前价格在近期价格区间中的平滑位置 / 动量状态。

它是首版最值得保留的 KDJ 核心信息。

### 加入 K 的变化量

建议加入：

```python
result["kdj_k_change_3d"] = k.diff(3)
```

该特征可以区分：

```text
60 → 70 → 80
```

和：

```text
95 → 88 → 80
```

两者当前 `K` 都为 `80`，但前者动量上升，后者动量下降。

### 优先测试 `K-D spread`，而非单独的 `D`

若后续决定计算 `D`，更值得测试的可能不是单独的 `kdj_d`，而是：

```python
result["kdj_spread"] = k - d
```

它直接描述：

> 快速动量相对于慢速动量的强弱。

传统金叉、死叉可以由 `K-D spread` 的符号穿越表达，但将连续信号离散为 0/1 会丢失偏离幅度、变化速度及持续性等信息。因此，连续的 `kdj_spread` 通常比金叉、死叉特征更值得优先验证。

---

## 与其他特征的互补关系

当前特征家族的职责可概括为：

| 特征          | 主要信息                   |
| ------------- | -------------------------- |
| DEMA spread   | 中期趋势方向、趋势强度     |
| MACD / PPO    | 中短期动量及动量变化       |
| `bb_position` | 价格在局部波动区间中的位置 |
| `bb_width`    | 当前波动率 regime          |
| `kdj_k`       | 近期高低价区间中的平滑位置 |

KDJ 与 Bollinger 的 `bb_position` 都描述价格相对位置，但基准不同：

```text
kdj_k：相对近期 high-low 区间的位置，经平滑后的动量状态
bb_position：相对均值与标准差带宽的位置
```

两者可能存在相关性，但市场含义并不完全相同。是否同时保留，应通过样本外结果验证，而不是仅凭指标名称判断。

---

## 推荐开发顺序

### 第一阶段

仅保留核心特征：

```python
result["kdj_k"] = k
result["kdj_k_change_3d"] = k.diff(3)
```

首先在 walk-forward 样本外验证其增量价值。

### 第二阶段

若特征重要度、SHAP 或 ablation test 显示 KDJ 有稳定贡献，再测试：

```python
result["kdj_spread"] = k - d
result["kdj_k_change_5d"] = k.diff(5)
```

其中，`kdj_spread` 表示快慢动量差，`kdj_k_change_5d` 则补充相对更长一点的动量变化尺度。

### 第三阶段

再考虑多窗口参数，例如：

```text
KDJ(9, 3, 3)
KDJ(14, 3, 3)
KDJ(20, 3, 3)
```

每增加一组特征，都应通过样本外 ablation test 验证其增量价值，避免无差别扩充高度相关的技术指标。
