# Price Momentum 特征设计

## 结论

当前 `compute_price_momentum` 将价格动量拆分为四类连续信息：**均线趋势结构**、**价格相对均线的位置**、**多周期历史收益**和**上涨日占比**。它们应主要作为模型或研究中的状态特征，而不是单独固化为“均线上穿即买入”或“短期涨幅为正即买入”的交易规则。

当前默认周期为 **5 / 10 / 20 / 60 / 120** 个交易日，分别近似对应一周、两周、一个月、一个季度和半年。第一版建议优先使用归一化后的连续字段：

| 特征组 | 当前字段 | 主要角色 | 是否建议首版输入模型 |
| --- | --- | --- | --- |
| 均线偏离 | `ma_{period}_bias` | 当前价格相对局部均值的位置 | 是 |
| 快慢均线比 | `ma_{short}_{long}_ratio` | 不同时间尺度趋势的一致性 | 是，注意冗余 |
| 历史收益 | `return_{period}d` | 不同 horizon 的绝对价格动量 | 是 |
| 上涨日比例 | `up_ratio_5d`、`up_ratio_20d` | 上涨方向的广度 / 持续性 | 是 |
| 均线水平 | `ma_{period}` | 平滑后的价格轨道 | 否，主要用于可视化或研究 |

这些特征均基于当日及此前价格计算。若预测未来收益，特征必须与目标收益严格按时间对齐，避免将未来价格带入训练样本。

## 当前实现与默认参数

当前实现核心如下：

```python
periods = [5, 10, 20, 60, 120]

for period in periods:
    ma = close.rolling(window=period, min_periods=1).mean()
    result[f"ma_{period}"] = ma
    result[f"ma_{period}_bias"] = (close - ma) / ma
    result[f"return_{period}d"] = close / close.shift(period) - 1

for short, long in itertools.pairwise(periods):
    result[f"ma_{short}_{long}_ratio"] = (
        result[f"ma_{short}"] / result[f"ma_{long}"]
    )
```

上涨日占比使用复权收盘价的日变化方向：

```python
delta = close.diff()
status = pd.Series(
    np.where(delta > 0, 1, np.where(delta < 0, -1, 0)),
    index=df.index,
)

result["up_ratio_5d"] = status.eq(1).rolling(5, min_periods=5).mean()
result["up_ratio_20d"] = status.eq(1).rolling(20, min_periods=20).mean()
```

其中平盘日的 `status = 0`：它不计作上涨日，也不计作下跌日。因此上涨日占比衡量的是窗口内“收盘价严格上涨”的天数比例。

## 均线：平滑价格轨道

长度为 $n$ 的简单移动平均（SMA）定义为：

$$
MA_{n,t} = \frac{1}{n}\sum_{i=0}^{n-1} Close_{t-i}
$$

当前实现使用 `min_periods=1`。因此在历史不足 $n$ 天时，均线仍会以已有观测值的平均数输出；第 $n$ 天及以后才是完整 $n$ 日均线。

| 周期 | 近似时间尺度 | 典型用途 |
| ---: | --- | --- |
| 5 | 一周 | 极短期价格节奏 |
| 10 | 两周 | 短期趋势 |
| 20 | 一个月 | 月度趋势背景 |
| 60 | 一季度 | 中期趋势背景 |
| 120 | 半年 | 较长期趋势背景 |

均线的绝对价格水平不宜直接作为跨股票模型输入：100 元股票与 10 元股票的均线数值没有直接可比性。其更适合用于图表，或进一步构造成相对指标。

---

## `ma_{period}_bias`：价格相对均线的位置

定义：

$$
bias_{n,t} = \frac{Close_t - MA_{n,t}}{MA_{n,t}}
$$

对应字段：

```text
ma_5_bias
ma_10_bias
ma_20_bias
ma_60_bias
ma_120_bias
```

| `bias` 状态 | 含义 |
| --- | --- |
| `> 0` | 当前价格位于该周期均线上方 |
| `< 0` | 当前价格位于该周期均线下方 |
| `≈ 0` | 当前价格接近该周期均线 |
| 正值持续扩大 | 价格相对均线的上行动量增强，也可能处于短期过度延伸 |
| 负值持续扩大 | 价格相对均线的下行动量增强，也可能出现超跌状态 |

它以均线为分母进行归一化，因此不同价格水平的股票之间更可比较。`bias` 本身不指定趋势会延续还是反转：同样的正偏离在强趋势中可能代表持续动量，在横盘市场中则可能更接近均值回归压力。应结合长期均线关系、波动率和成交量特征判断。

---

## `ma_{short}_{long}_ratio`：快慢趋势结构

当前仅计算相邻周期的均线比：

```text
ma_5_10_ratio
ma_10_20_ratio
ma_20_60_ratio
ma_60_120_ratio
```

定义为：

$$
ratio_{short,long,t} = \frac{MA_{short,t}}{MA_{long,t}}
$$

| 比率状态 | 含义 |
| --- | --- |
| `> 1` | 短周期均线高于长周期均线，近期价格相对偏强 |
| `< 1` | 短周期均线低于长周期均线，近期价格相对偏弱 |
| `≈ 1` | 两个时间尺度的平均价格接近 |
| 持续上升 | 快周期相对长周期正在改善 |
| 持续下降 | 快周期相对长周期正在走弱 |

它比离散的均线金叉 / 死叉保留了更多幅度信息。例如 `1.001` 和 `1.08` 都代表短均线在长均线上方，但趋势偏离程度明显不同。对树模型而言，这类连续变量通常比单日交叉标记更有信息量。

比率字段与对应的多个 `bias`、收益率字段存在相关性；是否全部保留应通过样本外 ablation test 决定，而不是仅按直觉叠加。

---

## `return_{period}d`：多周期价格动量

定义：

$$
return_{n,t} = \frac{Close_t}{Close_{t-n}} - 1
$$

当前字段：

```text
return_5d
return_10d
return_20d
return_60d
return_120d
```

| 收益为正 / 负 | 含义 |
| --- | --- |
| `return_5d > 0` | 当前价格高于 5 个交易日前，短期动量为正 |
| `return_20d > 0` | 当前价格高于约一个月前，中短期动量为正 |
| 短期正、长期负 | 可能是下跌趋势中的反弹，或趋势修复早期 |
| 短期负、长期正 | 可能是上升趋势中的回撤，或趋势转弱早期 |

收益率提供的是价格变化幅度；均线比率提供的是平滑后的趋势结构；两者相近但并不完全等价。多周期收益率可用于识别不同时间尺度是否同向，但不应直接被解释成下一期收益必然延续。

---

## `up_ratio`：上涨方向的广度

对于长度为 $n$ 的窗口：

$$
up\_ratio_{n,t} =
\frac{1}{n}\sum_{i=t-n+1}^{t}I(Close_i > Close_{i-1})
$$

当前输出：

```text
up_ratio_5d
up_ratio_20d
```

它只计数上涨日，不关心每次上涨或下跌的幅度。因此它补充了收益率：少数大涨日可以带来正收益率，但上涨日占比未必很高；反之，多数日小幅上涨也可能带来较高上涨日占比。

| `up_ratio` | 解读 |
| ---: | --- |
| `1.0` | 窗口内所有日均上涨 |
| `0.5` | 上涨日与非上涨日各约一半 |
| `0.0` | 窗口内没有上涨日 |
| `> 0.5` | 上涨日的频率占优 |
| `< 0.5` | 下跌或平盘日的频率占优 |

`up_ratio_5d - up_ratio_20d` 可作为研究中的短期广度变化指标：正值表示近期上涨日频率高于近一个月平均，负值则相反。当前实现没有直接输出该差值，如需加入模型，应先验证其对已有 `up_ratio` 特征的样本外增量价值。

## 特征使用策略

Price momentum 的合理角色是描述条件化的市场状态：

```text
长期趋势结构（ma_20_60_ratio、ma_60_120_ratio）
        +
短期偏离 / 动量（ma_5_bias、return_5d、return_10d）
        +
上涨广度（up_ratio_5d、up_ratio_20d）
        ↓
由模型或回测规则评估未来收益与风险
```

一个研究用的趋势延续候选状态可以是：中期快慢均线比大于 1、短期收益为正、且短期上涨日占比高于长期上涨日占比。一个均值回归候选状态则可能是：长期趋势仍为正，但短期 `bias` 显著为负。两者都只是**待验证的条件组合**，不是可直接上线的买卖信号。

应避免以下做法：

- 将 `ma_short_long_ratio > 1` 直接等同于买入；
- 将高 `return_5d` 直接等同于未来继续上涨；
- 将较低 `up_ratio` 直接等同于反弹；
- 在没有交易成本、滑点、停牌和可交易性假设的情况下，将特征规则当作策略收益。

## Warm-up、数据质量与时间对齐

| 字段 | 首个完整窗口 | 当前早期输出 |
| --- | ---: | --- |
| `ma_{period}`、`ma_{period}_bias` | 第 `period` 行 | 使用不足 `period` 条历史的均值 |
| `ma_{short}_{long}_ratio` | 取决于两条均线 | 可输出，但早期长均线尚未完整形成 |
| `return_{period}d` | 第 `period + 1` 行 | 前 `period` 行为 `NaN` |
| `up_ratio_5d` | 第 5 行 | 前 4 行为 `NaN` |
| `up_ratio_20d` | 第 20 行 | 前 19 行为 `NaN` |

`return` 与 `up_ratio` 的早期 `NaN` 表示历史不足，不应不加区分地填为 `0`；零收益或 50% 上涨日占比都是有实际含义的有效数值。

输入数据还应满足以下前提：

1. 按交易日期从早到晚排序；`rolling()` 与 `shift()` 按当前行顺序计算，不会自动排序。
2. 使用连续、口径一致的 `adj_close`。复权口径变化会扭曲收益、均线和日涨跌方向。
3. `periods` 应严格递增。相邻配对逻辑以传入顺序定义 `short` 与 `long`。
4. 均线作为分母，`adj_close` 与均线应为正且非零；异常值应在特征计算前处理。

## 验证建议

1. **时间序列切分**：使用 walk-forward 或 expanding-window 验证，不能随机打乱日频样本。
2. **特征消融**：分别比较“收益率”“均线偏离 / 比率”“上涨日比例”以及三者组合的样本外表现，识别冗余特征。
3. **按市场状态分层**：分别检验上升、下降、高波动与低波动阶段；动量与均值回归的有效性常依赖市场环境。
4. **目标与持有期匹配**：短周期特征可先检验未来 1 / 5 日收益，中长期特征可检验未来 10 / 20 日收益；最终仍以实际预测目标为准。
5. **组合层回测**：将预测或排序结果转化为可交易组合时，纳入交易成本、滑点、换手、停牌、涨跌停和流动性约束。

特征的最终价值不取决于其技术分析名称，而取决于它在严格时间对齐、样本外且计入交易约束后的增量解释能力。
