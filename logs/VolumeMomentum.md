# Volume Momentum 特征设计

## 结论

当前 `compute_volume_momentum` 将成交量变化拆分为三类连续信息：**成交量相对均值的偏离**、**多周期成交量变化**和**快慢成交量均线比率**。它们用于描述市场参与度是在扩张还是收缩，以及这种变化发生在哪个时间尺度；不应单独被解释为买入或卖出信号。

默认周期为 **5 / 10 / 20 / 60** 个交易日，约对应一周、两周、一个月和一个季度。

| 特征组 | 当前字段 | 主要角色 | 是否建议首版输入模型 |
| --- | --- | --- | --- |
| 成交量偏离 | `vol_ma_{period}_bias` | 当日成交量相对局部常态是否异常 | 是 |
| 成交量变化 | `vol_change_{period}d` | 当前参与度相对过去某日的变化幅度 | 是，注意极端值 |
| 快慢均量比 | `vol_ma_{short}_{long}_ratio` | 短期参与度相对长期趋势是否扩张 | 是，注意冗余 |
| 成交量均线水平 | `vol_ma_{period}` | 平滑后的成交量轨道 | 否，主要用于构造派生特征 |

这些字段仅使用当日及之前的 `adj_vol` 计算。若用于预测未来收益，必须与目标收益严格按时间对齐，避免未来数据泄漏。

---

## 当前实现与默认参数

实现使用复权成交量 `adj_vol`。

`periods` 必须按升序传入；相邻配对逻辑会依次生成 `5/10`、`10/20`、`20/60` 的均量比。

---

## `vol_ma_{period}`：平滑成交量基准

长度为 $n$ 的成交量简单移动平均定义为：

$$
VolMA_{n,t} = \frac{1}{n}\sum_{i=0}^{n-1} Volume_{t-i}
$$

当前使用 `min_periods=1`，所以历史不足 $n$ 天时仍会输出已有数据的平均值；第 $n$ 行及以后才是完整的 $n$ 日均量。

| 周期 | 近似时间尺度 | 主要用途 |
| ---: | --- | --- |
| 5 | 一周 | 捕捉短期放量或缩量 |
| 10 | 两周 | 平滑短期参与度 |
| 20 | 一个月 | 月度成交量常态 |
| 60 | 一季度 | 中期参与度基准 |

均量绝对值受股票规模、流通盘和数据口径影响，通常不适合作为跨股票模型的直接输入。因此当前元数据集合不将 `vol_ma_{period}` 作为训练特征，而将其用于构造归一化特征。

---

## `vol_ma_{period}_bias`：异常成交量程度

定义：

$$
vol\_ma\_{n}\_bias_t = \frac{Volume_t - VolMA_{n,t}}{VolMA_{n,t}}
$$
| Bias 状态 | 含义 |
| --- | --- |
| `> 0` | 当日成交量高于该周期平均水平 |
| `< 0` | 当日成交量低于该周期平均水平 |
| `≈ 0` | 当日成交量接近近期常态 |
| 明显正值 | 放量；可能对应突破、恐慌、事件或调仓 |
| 明显负值 | 缩量；可能对应观望、盘整或趋势参与度下降 |

例如 `vol_ma_20_bias = 0.5` 表示当日成交量比 20 日均量高 50%。它只衡量参与度是否异常，**不含价格方向**：上涨放量与下跌放量都会产生正 bias。方向确认应结合价格收益、趋势或 `OBV.md` 中的方向性成交量流特征。

---

## `vol_change_{period}d`：多周期成交量变化

定义：

$$
vol\_change\_{n}d_t = \frac{Volume_t}{Volume_{t-n}} - 1
$$
它将今天的成交量直接与 $n$ 个交易日前比较。

| 状态 | 含义 |
| --- | --- |
| `> 0` | 今日成交量高于 `n` 日前 |
| `< 0` | 今日成交量低于 `n` 日前 |
| `= 0` | 两日成交量相同 |
| 较大正值 | 相对某个历史点明显放量 |
| 接近 `-1` | 当前成交量远低于该历史点 |

该特征比均量 bias 更敏感于“基准日”本身的异常成交量：若 $t-n$ 恰逢一次事件性放量，随后即使成交量仍高于正常水平，`vol_change_{n}d` 也可能为负。因此它与滚动均量偏离互补，也更容易出现极端值；当前特征元数据对其启用 winsorize 和行业中性化。

---

## `vol_ma_{short}_{long}_ratio`：短长周期参与度结构

定义：

$$
vol\_ma\_{short,long\_ratio,t} = \frac{VolMA_{short,t}}{VolMA_{long,t}}
$$

当前输出相邻周期组合。

| 比率状态 | 含义 |
| --- | --- |
| `> 1` | 短期平均成交量高于长期平均，参与度正扩张 |
| `< 1` | 短期平均成交量低于长期平均，参与度正收缩 |
| `≈ 1` | 短长周期参与度接近 |
| 持续上升 | 短期相对长期的放量正在增强 |
| 持续下降 | 短期相对长期的缩量正在加深 |

与单日 bias 相比，该比率更平滑，较少受一天成交量冲击影响；它描述的是一段时间内成交量水平的结构变化。它依然不包含价格方向，因此“放量上攻”和“放量下跌”需要由价格类特征区分。

## 与价格和 OBV 特征的关系

| 特征类别 | 主要回答的问题 | 是否包含价格方向 |
| --- | --- | --- |
| Volume Momentum | 参与度相对历史是在扩张还是收缩？ | 否 |
| Price Momentum | 价格趋势、偏离和历史收益如何？ | 是 |
| OBV flow strength | 成交量主要发生在上涨日还是下跌日？ | 是，以收盘价涨跌赋方向 |

因此，成交量动量适合作为价格信号的条件变量。例如，正价格动量同时伴随 `vol_ma_20_bias > 0` 或 `vol_ma_20_60_ratio > 1`，可表示该价格变动有更高的市场参与度；但这仍是待检验的特征组合，不构成交易规则。

## Warm-up、边界情况与数据质量

| 字段 | 首个完整窗口 / 有效值 | 当前早期输出 |
| --- | ---: | --- |
| `vol_ma_{period}`、`vol_ma_{period}_bias` | 第 `period` 行 | 使用不足 `period` 条历史的均值 |
| `vol_ma_{short}_{long}_ratio` | 取决于最长均线 | 可输出，但早期长均线尚未完整形成 |
| `vol_change_{period}d` | 第 `period + 1` 行 | 前 `period` 行为 `NaN` |

注意以下边界条件：

- 若 `adj_vol`、均量或 `adj_vol.shift(period)` 为零，除法可能产生 `NaN` 或无穷值；这些值应先保留以暴露数据质量问题，再按统一的特征清洗规则处理。
- `rolling()` 和 `shift()` 按 DataFrame 当前行顺序计算，输入必须按交易日期从早到晚排序。
- 复权成交量的口径应在训练、回测和线上推理中保持一致；口径切换会制造伪放量或缩量。
- 停牌、缺失成交量、拆并股或数据源修订都可能造成异常值，不能自动解释为交易信号。

不建议把 warm-up 产生的 `NaN` 直接填为 `0`：前者代表历史不足，后者代表一个有明确经济含义的“无变化 / 无偏离”数值。

## 验证建议

1. 使用 walk-forward 或 expanding-window 切分，避免随机打乱日频样本。
2. 分别检验 bias、直接变化率和快慢均量比，再做消融实验，识别与价格动量或换手率的冗余。
3. 按价格趋势方向、波动率状态、流动性和事件日分层，观察成交量扩张的预测含义是否稳定。
4. 在组合回测中加入成交量和可交易性约束；异常放量可能同时意味着机会、风险或交易冲击成本上升。

这些特征的价值取决于严格时间对齐后的样本外增量解释能力，而不是“放量必涨”或“缩量必跌”等固定技术分析结论。

## 常见解读与阈值

下表的区间与事件用于描述指标状态，是研究参照而非独立的交易指令。

| 成交量状态或事件 | 常见解读 |
| --- | --- |
| `vol_ma_{period}_bias` 为正且较高 | 当前成交量显著高于近期常态，参与度可能增强。 |
| `vol_ma_{period}_bias` 为负且较低 | 当前成交量低于近期常态，参与度可能减弱。 |
| 短期均量高于长期均量 | 近期参与度可能在扩张。 |
| `vol_change_{period}d` 显著变化 | 成交量相对过去发生明显变化，应结合价格方向解释。 |
| 放量并伴随价格同向突破 | 参与度可为价格趋势提供确认，但应排除事件性冲击。 |
| 放量而价格方向不明 | 可能反映换手或分歧，不宜直接推断后续涨跌。 |

放量或缩量都不直接给出价格方向，阈值应结合流动性和市场状态验证。
