# 技术指标类型与相互关系

## 结论

当前指标不应被视为彼此独立的买卖信号，而应被拆分为不同的市场信息维度：

| 信息维度 | 指标 / 特征 | 主要回答的问题 |
| --- | --- | --- |
| 趋势结构 | DEMA spread | 中期趋势方向是否存在、强度如何？ |
| 动量及其变化 | MACD / PPO、RSI | 近期上涨或下跌动量是否占优、是否正在变化？ |
| 局部价格位置 | KDJ、`bb_position` | 当前价格在近期价格区间或波动区间的什么位置？ |
| 波动率状态 | `bb_width` | 市场处于波动收缩、扩张还是高波动状态？ |

这些维度存在相关性，但计算基准、时间尺度和表达方式不同。首版应优先保留连续特征，让模型在趋势、动量、位置和波动率状态的组合中学习条件关系；不应机械地把金叉、死叉、超买、超卖固化为交易规则。

---

## 指标分类

### 趋势结构：DEMA

DEMA(20, 60) 通过快、慢双重指数均线的相对位置描述中期趋势结构。

| 特征 | 信息含义 |
| --- | --- |
| `dema_20_60_spread` | 当前趋势方向与趋势强度 |
| `dema_20_60_spread_change_5d` | 趋势是在增强还是减弱 |
| 金叉 / 死叉 | 趋势状态穿越零轴的离散事件 |

`dema_20_60_spread` 为正，表示快速 DEMA 高于慢速 DEMA，通常对应多头趋势；为负则通常对应空头趋势。其绝对值越大，快慢趋势线的偏离越明显。

DEMA 的核心角色是提供**趋势背景**：其他指标的同一数值，在上升趋势、下降趋势和横盘状态中可能具有不同含义。

### 动量及动量变化：MACD / PPO

当前 MACD 使用 12 / 26 / 9 参数组合，其 `diff` 实际是快慢 EMA 的归一化偏离，形式接近 PPO。

| 特征 | 信息含义 |
| --- | --- |
| `macd_diff` | 中短期趋势或动量强度 |
| `macd_dea` | 平滑后的动量趋势 |
| `macd_hist` | 动量相对信号线的变化，可视为动量变化强度 |

MACD 12 / 26 / 9 相比 DEMA 20 / 60 更敏感，主要补充中短期动量及动量切换信息。

### 相对涨跌动量：RSI

RSI 衡量股票自身平滑后的上涨幅度在上涨与下跌总幅度中所占比例。

| 特征 | 信息含义 |
| --- | --- |
| `rsi_6` | 更敏感的短期相对涨跌动量 |
| `rsi_14` | 更平滑的中短期相对涨跌动量 |
| 超买 / 超卖字段 | RSI 是否跨越 70 / 30 的离散状态 |

RSI 与 MACD 都属于动量类特征，但表达方式不同：MACD 比较快、慢均线的相对偏离；RSI 比较近期上涨幅度和下跌幅度的相对占比。RSI 被限制在 0 到 100，适合表达有界的相对强弱状态。

### 局部价格位置：KDJ

KDJ 的核心是收盘价位于近期 high-low 区间的相对位置。当前重点使用 `kdj_k`，即 RSV 经平滑后得到的短期位置 / 动量状态。

| 特征 | 信息含义 |
| --- | --- |
| `kdj_k` | 平滑后的近期高低价区间位置 |
| `kdj_k_change_3d` | 该位置对应的短期动量变化 |
| `kdj_spread` | 若后续计算 D，则表示快慢动量差 |

KDJ 的位置基准是近期最高价与最低价，因此它描述的是价格在**极值区间**中的位置。

### 局部价格位置与波动率状态：Bollinger Bands

Bollinger Bands 同时提供价格位置和波动率两个维度。

| 特征 | 信息含义 |
| --- | --- |
| `bb_position` | 收盘价相对中轨、上下轨的标准化位置 |
| `bb_width` | 归一化后的局部波动率状态 |

`bb_position` 的基准是滚动均值与标准差带宽，表示价格相对近期均值偏离了多少；`bb_width` 则描述价格区间本身有多宽。

## 信息维度与时间尺度

| 指标 / 特征 | 主要维度 | 默认时间尺度 | 是否有界 | 是否直接描述波动率 |
| --- | --- | --- | --- | --- |
| DEMA 20 / 60 spread | 趋势结构 | 中期 | 否 | 否 |
| MACD / PPO 12 / 26 / 9 | 动量与动量变化 | 中短期 | 否 | 否 |
| `rsi_6` | 相对涨跌动量 | 短期 | 是，0–100 | 否 |
| `rsi_14` | 相对涨跌动量 | 中短期 | 是，0–100 | 否 |
| `kdj_k` | 高低价区间位置 | 短期 | 通常为 0–100 | 间接反映区间位置 |
| `bb_position` | 均值—标准差区间位置 | 约一个交易月 | 否，可突破上下轨 | 否 |
| `bb_width` | 波动率状态 | 约一个交易月 | 否 | 是 |

时间尺度并非绝对的截断边界。DEMA、MACD 与 RSI 使用递归平滑，更早的数据会以逐渐衰减的权重影响当前值；Bollinger Bands 与 KDJ 使用滚动窗口，窗口外历史不直接参与当前计算。

## 主要重叠关系

### DEMA 与 MACD：趋势和动量的部分重叠

DEMA spread 与 MACD / PPO 都通过快慢平滑价格的相对位置表达方向性信息：

| 指标 | 平滑方法 | 默认尺度 | 更强调的信息 |
| --- | --- | --- | --- |
| DEMA spread | 快慢 DEMA | 20 / 60 | 中期趋势结构与强度 |
| MACD / PPO | 快慢 EMA 与信号线 | 12 / 26 / 9 | 中短期动量及其变化 |

二者存在较高相关性的可能，尤其在单边趋势中。但 MACD 使用更短周期，并通过柱状图补充动量相对信号线的变化，因此不等同于 DEMA。

若 MACD 也改为 20 / 60，则会与 DEMA 20 / 60 在底层含义上更接近，特征冗余会明显增加。

### RSI 与 MACD：同属动量，计算对象不同

| 指标 | 比较对象 | 主要表达 |
| --- | --- | --- |
| RSI | 平滑上涨幅度与平滑下跌幅度 | 买卖方向的相对占优程度 |
| MACD / PPO | 快、慢 EMA | 不同时间尺度价格趋势的偏离与变化 |

两者都可能在上涨时偏高、下跌时偏低，但 RSI 更直接回答“近期上涨是否相对占优”，MACD 更直接回答“短期趋势是否偏离较慢趋势，以及该偏离是否加速”。

`rsi_6` 与 `rsi_14` 的组合还表达了短期动量相对中短期动量是增强还是减弱，这与 MACD 柱状图有一定交集，应通过 ablation test 检验其联合价值。

### KDJ 与 Bollinger `bb_position`：同属位置，参考系不同

KDJ 与 `bb_position` 都描述当前价格的局部位置，但基准不同：

| 特征 | 位置参考系 | 核心含义 |
| --- | --- | --- |
| `kdj_k` | 近期 high-low 极值区间 | 当前收盘价接近区间顶部还是底部，并经平滑 |
| `bb_position` | 滚动均值与标准差带 | 当前价格相对近期均值偏离的程度 |

当价格接近近期最高点时，`kdj_k` 往往较高；当价格高于均值并接近或突破上轨时，`bb_position` 往往较高。但两者并不等价：价格可能位于较窄区间上沿，却未明显偏离均值；也可能显著高于均值，却因近期区间快速上移而不在高低价区间极端位置。

### RSI 与 KDJ：短期动量和位置的部分重叠

RSI 与 KDJ 都常进入传统“超买 / 超卖”区域，但它们的数学来源不同：

| 特征 | 核心来源 |
| --- | --- |
| RSI | 上涨与下跌幅度的平滑比例 |
| KDJ | 收盘价在近期 high-low 区间中的位置 |

在持续上涨中，两者通常共同走高；在震荡或跳空行情中，二者可能给出不同状态。它们可以同时保留，但不应因传统阈值相似而被解释为两份独立的反转证据。

### `bb_width` 与其他指标：波动率维度的补充

`bb_width` 与 DEMA、MACD、RSI、KDJ 的主要区别在于：它不直接给出上涨或下跌方向，而是描述市场波动率状态。

| `bb_width` 状态 | 与其他特征结合时的作用 |
| --- | --- |
| 较低 | 可识别盘整或波动收缩环境；方向仍需由趋势、动量判断 |
| 开始上升 | 可识别波动扩张；有助于区分突破与低波动震荡 |
| 较高 | 可识别高波动环境；同一动量信号的风险与持续性可能不同 |

因此，`bb_width` 的价值往往不在于单独预测方向，而在于为趋势、动量和位置特征提供 volatility regime 条件。

## 指标组合的条件解释

单一指标的传统解释通常不充分，更有价值的是将不同维度组合为市场状态。

| 趋势 | 动量 | 位置 / 波动率 | 可能的市场状态 |
| --- | --- | --- | --- |
| DEMA spread 为正 | MACD、RSI 均偏强 | `bb_position` 较高且 `bb_width` 扩张 | 趋势突破或动量延续的可能性增加 |
| DEMA spread 接近零 | RSI 或 KDJ 进入极端 | `bb_width` 较低 | 震荡环境中的局部均值回归可能性增加 |
| DEMA spread 为负 | MACD、RSI 均偏弱 | `bb_position` 较低且 `bb_width` 扩张 | 下行趋势延续或波动放大的可能性增加 |
| DEMA spread 为正 | 短期 RSI / KDJ 走弱 | 带宽不扩张或收缩 | 上升趋势中的短期动量减弱，是否回撤需由数据验证 |

表中均为条件性描述，不是交易规则。同一组合在不同股票、市场阶段和预测周期下，可能对应不同的未来收益分布。

## 特征冗余与保留原则

### 优先使用连续状态，而非离散事件

| 连续特征 | 对应的离散表达 | 原因 |
| --- | --- | --- |
| DEMA spread | 金叉 / 死叉 | 保留趋势方向、强度、持续时间和变化幅度 |
| MACD histogram | 金叉 / 死叉 | 保留动量偏离及其变化强度 |
| RSI | 超买 / 超卖 | 保留极端程度与接近阈值的过程信息 |
| KDJ spread 或 K | KDJ 金叉 / 死叉 | 保留快慢动量偏离幅度与速度 |
| `bb_position` | 上轨 / 下轨触碰 | 保留突破上下轨的幅度 |

二元信号可用于研究或作为补充变量，但通常不应替代对应的连续特征。

### 先覆盖不同维度，再增加相近指标

第一阶段应优先覆盖趋势、动量、位置和波动率，而不是在同一维度内增加大量相近参数：

| 优先级 | 目标 | 代表特征 |
| --- | --- | --- |
| 高 | 覆盖中期趋势 | `dema_20_60_spread` |
| 高 | 覆盖中短期 / 短期动量 | `macd_diff`、`macd_hist`、`rsi_6`、`rsi_14` |
| 高 | 覆盖局部位置 | `kdj_k`、`bb_position` |
| 高 | 覆盖波动率状态 | `bb_width` |
| 低 | 增加相邻参数的同类指标 | 相近窗口的 DEMA、RSI、MACD、KDJ |
| 低 | 仅增加传统阈值或交叉标签 | 金叉、死叉、超买、超卖 |

相近指标是否冗余不能只凭名称或相关系数判断。对非线性模型而言，一个特征可能主要通过与趋势或波动率状态的交互产生价值。因此，最终应通过时间序列交叉验证与消融实验判断。

## 推荐研究框架

1. 以 DEMA spread 作为趋势背景。
2. 使用 MACD / PPO 与 RSI 描述不同时间尺度的动量状态及变化。
3. 使用 KDJ 和 `bb_position` 描述价格的局部位置，但关注其不同参考系带来的增量信息。
4. 使用 `bb_width` 标识波动收缩、扩张与高波动 regime。
5. 在 walk-forward 样本外验证中，分别比较：基础特征集、加入单一指标家族、加入指标交互后的效果。
6. 检查未来收益分组、Rank IC、分年度表现、特征重要度与 SHAP，确认价值是否稳定。

核心原则是：技术指标是不同价格历史变换形成的特征，而不是天然有效的交易规则。应由样本外数据验证每个特征及其组合在目标预测周期内是否提供稳定的增量信息。

## 常见解读与阈值

下表的区间与事件用于描述指标状态，是研究参照而非独立的交易指令。

| 解读原则 | 常见解读 |
| --- | --- |
| 趋势、动量、位置和波动率指向一致 | 信号一致性较高，但仍不代表确定的未来收益。 |
| 相近指标同时触发 | 可能只是同一信息维度的重复表达，不应重复计权。 |
| 指标出现分歧 | 应结合市场状态判断，不宜以单一固定阈值下结论。 |
| 趋势与动量一致、波动率扩张 | 趋势延续的候选状态，但仍需比较不同市场阶段的表现。 |
| 位置指标极端而趋势仍强 | 可能是趋势延续，也可能是反转前兆，不能只按极端值反向操作。 |

各指标的具体阈值应以对应特征文档为准，并通过样本外验证确定。
