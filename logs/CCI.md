# CCI 特征设计

## 结论

`compute_cci` 使用复权后的最高价、最低价和收盘价计算 Commodity Channel Index（CCI）。它衡量的是：**当前价格相对近期“正常价格区间”偏离了多少**。CCI 不看绝对价格高低，而看当前走势是否显著偏强或偏弱。

默认使用 **14 日**窗口生成 `cci`，并额外生成 **5 日**平滑均线 `cci_ma_5`。首版应优先将连续的 `cci` 及其平滑值作为研究或模型特征；`±100` 的突破、跌破和回归更适合用作可视化及条件研究事件，而不应脱离市场状态机械地产生交易指令。

| 字段 | 主要角色 | 首版模型建议 |
| --- | --- | --- |
| `cci` | 当前典型价格相对近期常态的标准化偏离 | 是 |
| `cci_ma_5` | CCI 的短期平滑状态 | 可选，需做消融验证 |

---

## 当前实现与参数

实现需要输入 `adj_high`、`adj_low` 和 `adj_close`，并假设 DataFrame 已按交易日期从早到晚排序：

```python
window = 14
periods = [5]

tp = (df["adj_high"] + df["adj_low"] + df["adj_close"]) / 3
tp_sma = tp.rolling(window=window, min_periods=window).mean()
md = tp.rolling(window=window, min_periods=window).apply(
    lambda values: np.mean(np.abs(values - values.mean())),
    raw=True,
)

cci = (tp - tp_sma) / (0.015 * md.replace(0, np.nan))
result["cci"] = cci
result["cci_ma_5"] = cci.rolling(window=5, min_periods=5).mean()
```

其中常数 `0.015` 来自 CCI 提出者 Donald Lambert 的原始定义。它用于让多数常态市场下的 CCI 值大致落在 `-100` 到 `+100` 附近；这不是严格保证，也不表示 `±100` 是跨资产恒定有效的交易阈值。

## 指标定义

### Typical Price：典型价格

CCI 不直接只使用收盘价，而是先定义典型价格：

$$
TP_t = \frac{High_t + Low_t + Close_t}{3}
$$

当前实现使用复权后的 `adj_high`、`adj_low` 与 `adj_close`。因此，CCI 同时吸收收盘位置和日内价格区间的信息。

### Typical Price Moving Average：近期正常水平

对长度为 $n$ 的窗口：

$$
SMA_{TP,t} = \frac{1}{n} \sum_{i=t-n+1}^{t} TP_i
$$

默认 `window=14` 时，`tp_sma` 代表近期约三周交易日的典型价格均值。分子 $TP_t - SMA_{TP,t}$ 表示当前典型价格相对近期中心的偏离方向与绝对距离。

### Mean Deviation：近期正常波动尺度

当前实现使用同一窗口内典型价格相对窗口均值的平均绝对偏差：

$$
MD_t = \frac{1}{n} \sum_{i=t-n+1}^{t}
\left|TP_i - SMA_{TP,t}\right|
$$

它不是标准差，而是平均绝对偏差。用 $MD_t$ 标准化后，CCI 表示当前偏离相对于近期正常价格波动尺度有多显著。

### CCI

$$
CCI_t = \frac{TP_t - SMA_{TP,t}}{0.015 \times MD_t}
$$

| CCI 状态 | 含义 |
| --- | --- |
| `CCI > 0` | 当前典型价格高于近期均值 |
| `CCI < 0` | 当前典型价格低于近期均值 |
| 绝对值扩大 | 偏离近期常态的程度正在增大 |
| 接近 `0` | 当前典型价格接近近期均值 |

## 常见解读与阈值

| CCI 区间或事件 | 常见解读 |
| --- | --- |
| `CCI > +100` | 价格显著强于近期均值，市场可能处在强势上行或超买状态。 |
| `CCI < -100` | 价格显著弱于近期均值，市场可能处在弱势下行或超卖状态。 |
| `-100 ≤ CCI ≤ +100` | 通常视为相对常态的震荡区间。 |
| 从下向上突破 `+100` | 常被当作动量转强、可能进入上涨趋势的信号。 |
| 从上向下跌破 `-100` | 常被当作动量转弱、可能进入下跌趋势的信号。 |
| 从低位重新上穿 `-100` | 在震荡或反转策略中，常作为“超卖修复”的候选买入信号。 |
| 从高位重新下穿 `+100` | 常作为“超买回落”的候选卖出或减仓信号。 |

“超买”不等于价格必须下跌，“超卖”也不等于价格必须上涨。CCI 在强趋势中可以长期停留在 `+100` 上方或 `-100` 下方，因此阈值应结合趋势、成交量、波动率和交易成本验证。

## 先判断市场状态

实务上，先判断市场类型更重要：

| 市场状态 | CCI 更适合的用法 |
| --- | --- |
| 明确上升趋势 | 关注突破 `+100`，或回落后重新转强；不要仅因数值高就做空。 |
| 明确下降趋势 | 关注跌破 `-100`，或反弹失败后转弱；不要仅因数值低就抄底。 |
| 区间震荡 | 关注低于 `-100` 后的回升，以及高于 `+100` 后的回落。 |

因此，可将 CCI 理解为“偏离强度”与“动量状态”的连续描述：趋势环境中更关注同向突破和重新转强，震荡环境中才更适合研究均值回归式的阈值回归。

## `cci_ma_5`：CCI 的短期平滑

当前默认平滑值为：

$$
CCI\_MA_{5,t} = \frac{1}{5} \sum_{i=t-4}^{t} CCI_i
$$

它降低单日 CCI 的噪声，便于观察 CCI 的持续方向和变化速度：

| `cci` 与 `cci_ma_5` | 可研究的状态 |
| --- | --- |
| `cci` 高于均线且均线向上 | 短期偏强状态可能在增强 |
| `cci` 低于均线且均线向下 | 短期偏弱状态可能在增强 |
| CCI 围绕均线频繁交叉 | 市场可能震荡，单一交叉信号噪声较高 |

这些交叉仅是连续特征关系的辅助观察，不应在没有样本外验证时直接固化为买卖规则。

## Warm-up、缺失值与边界情况

| 字段 | 所需历史 | 无其他缺失时首次有效值 |
| --- | --- | --- |
| `cci` | 14 个典型价格观测值 | 第 14 个价格观测值 |
| `cci_ma_5` | 首个有效 CCI 后再累积 5 个 CCI 值 | 第 18 个价格观测值 |

- 当前使用 `min_periods=window`，窗口未完整时输出 `NaN`，不应用 `0` 替代历史不足。
- 当窗口内典型价格完全不变时，`md = 0`。实现会以 `md.replace(0, np.nan)` 避免除零；此时 CCI 为 `NaN`，而不是可解释的强弱信号。
- 缺失或异常的复权高、低、收盘价会传播至后续滚动窗口，应先检查原始行情质量。
- `rolling()` 按当前行顺序计算，因此输入必须按交易日期升序排列。

## 可视化

`vis_cci(stock_df, cci_df, window=14, periods=(5,))` 建议使用两个共享横轴面板，并以等距序号 `x = range(len(plot_df))` 作为横坐标位置：

1. 顶部价格面板：复权高低价区间、复权收盘价、典型价格及其 14 日均线。它直接展示 CCI 分子所依据的价格背景；
2. 底部 CCI 面板：`cci`、`cci_ma_5`、`0` 轴及 `±100` 参考线，便于观察偏离程度和阈值事件。

调用示例：

```python
stock.set_index("trade_date", inplace=True)
cci_features = compute_cci(stock, window=14, periods=[5])
vis_cci(stock, cci_features, window=14, periods=(5,))
```

## 验证建议

- 对趋势延续与均值回归两类假设分别回测，不要混合解释 `±100` 阈值。
- 按趋势状态、波动率状态、成交量/换手率和行业分层，检查 CCI 的效果是否稳定。
- 对 `cci`、`cci_ma_5` 及阈值突破事件做样本外 walk-forward 或 expanding-window 测试，并进行消融实验。
- 在实际策略评估中纳入可交易性、滑点、手续费和持仓约束；技术指标本身不保证经济收益。
