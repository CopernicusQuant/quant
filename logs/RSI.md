# RSI 特征设计

## 结论

RSI（Relative Strength Index，相对强弱指数）在本项目中同时使用 **6 / 14** 两个周期，用于描述一只股票自身近期上涨幅度与下跌幅度的相对强弱。

| 特征组   | 时间尺度 | 主要角色                     |
| -------- | -------- | ---------------------------- |
| `rsi_6`  | 短期     | 更敏感地描述近期涨跌动量变化 |
| `rsi_14` | 中短期   | 更平滑地描述经典相对强弱状态 |

当前每个周期还生成基于传统 70 / 30 阈值的状态标签：

| RSI 特征             | 含义          |
| -------------------- | ------------- |
| `rsi_6_over_bought`  | `rsi_6 > 70`  |
| `rsi_6_over_sold`    | `rsi_6 < 30`  |
| `rsi_14_over_bought` | `rsi_14 > 70` |
| `rsi_14_over_sold`   | `rsi_14 < 30` |

`rsi_6` 和 `rsi_14` 是连续特征；超买、超卖字段是离散状态标签。用于模型时，应优先验证连续 RSI 的样本外增量价值，而不是预先将“超买”或“超卖”解释为反转交易信号。

---

## 指标定义

令每日复权收盘价变化为：

$$
\Delta_t = Close_t - Close_{t-1}
$$

将变化拆分为上涨和下跌的绝对幅度：

$$
Gain_t = \max(\Delta_t, 0)
$$

$$
Loss_t = \max(-\Delta_t, 0)
$$

对二者分别平滑，得到 $AvgGain_t$ 和 $AvgLoss_t$。RSI 定义为：

$$
RSI_t = 100 \times \frac{AvgGain_t}{AvgGain_t + AvgLoss_t}
$$

也可先计算相对强度：

$$
RS_t = \frac{AvgGain_t}{AvgLoss_t}
$$

再得到：

$$
RSI_t = 100 - \frac{100}{1 + RS_t}
$$

两种写法在分母非零时等价。

“相对强弱”指该股票上涨与下跌相比较，不是与大盘、行业或其他股票比较。

| RSI 水平          | 含义                           |
| ----------------- | ------------------------------ |
| `RSI > 50`        | 平滑后的上涨幅度占优势         |
| `RSI = 50`        | 平滑后的上涨与下跌幅度相当     |
| `RSI < 50`        | 平滑后的下跌幅度占优势         |
| 接近 `100` 或 `0` | 近期价格运动明显偏向上涨或下跌 |

例如，`RSI = 70` 表示平滑后的上涨幅度约占上涨与下跌总幅度的 70%。它**不表示价格上涨了 70%**，也不表示未来上涨或下跌的概率为 70%。RSI 反映方向上的相对强弱，不能单独说明涨跌幅度大小、估值高低或未来收益方向。

## 当前实现：6 / 14 双周期

项目默认计算 `RSI(6)` 与 `RSI(14)`。两者使用相同的计算方式，仅平滑周期不同。

| 周期 | 平滑系数 $\alpha$    | 特征表现                       | 用途                       |
| ---- | -------------------- | ------------------------------ | -------------------------- |
| `6`  | $1/6 \approx 0.167$  | 对近期价格变化反应快、噪声较大 | 捕捉短期动量变化或状态切换 |
| `14` | $1/14 \approx 0.071$ | 反应较慢、曲线更平滑           | 描述中短期的相对强弱状态   |

`RSI(6)` 和 `RSI(14)` 不完全独立，但它们的差异本身包含时间尺度信息：

| 状态                      | 可能含义                             |
| ------------------------- | ------------------------------------ |
| `rsi_6` 明显高于 `rsi_14` | 最近上涨动量相对过去一段时间正在增强 |
| `rsi_6` 明显低于 `rsi_14` | 最近下跌动量相对过去一段时间正在增强 |

因此，6 / 14 的组合同时提供短期敏感性与较平滑的相对强弱状态。是否同时保留两者作为模型输入，仍应以样本外 ablation test 验证。

## 平滑口径与 Wilder RSI

当前实现采用递归指数平滑，平滑系数为：

$$
\alpha = \frac{1}{period}
$$

其递推形式为：

$$
AvgGain_t = \frac{period-1}{period}AvgGain_{t-1} + \frac{1}{period}Gain_t
$$

$$
AvgLoss_t = \frac{period-1}{period}AvgLoss_{t-1} + \frac{1}{period}Loss_t
$$

该平滑系数与 Wilder RSI 一致，但初始化方式不同。

标准 Wilder RSI 会先用前 `period` 个价格变化计算上涨和下跌幅度的简单平均，随后再进行递推。当前实现从序列起点开始递归平滑，且首日没有前一日价格变化时按零变化处理。

| 项目          | 当前实现                     | 严格 Wilder 初始化               |
| ------------- | ---------------------------- | -------------------------------- |
| 平滑系数      | $1 / period$                 | $1 / period$                     |
| 初始平滑值    | 从序列首日的零变化开始递推   | 前 `period` 个涨跌变化的简单平均 |
| 首个 RSI 输出 | 序列开始即可能有数值或 `NaN` | 第 `period` 个价格变化后才有效   |
| 早期数值      | 受初始值影响                 | 符合传统 Wilder 定义             |

两种口径的差异主要集中在序列开始阶段，影响会随时间逐渐衰减。当前口径可以继续使用，但训练、回测与生产计算必须保持一致。若未来需要与严格 Wilder 或外部技术指标库逐项对齐，应同步修改实现与预热期处理。

RSI 不是严格的截断滚动窗口：即使周期为 6 或 14，更早的涨跌变化仍会以递减权重影响当前结果。

## 超买与超卖：状态而非反转信号

传统上通常将以下状态称为超买、超卖：

| 条件       | 状态 |
| ---------- | ---- |
| `RSI > 70` | 超买 |
| `RSI < 30` | 超卖 |

这些是状态标签，**不能直接作为反转信号**。

| 市场环境 | RSI 持续偏高的可能含义                     | RSI 持续偏低的可能含义                     |
| -------- | ------------------------------------------ | ------------------------------------------ |
| 强趋势   | 上涨动量强，RSI 可长期位于 70 附近或以上   | 下跌动量强，RSI 可长期位于 30 附近或以下   |
| 横盘     | 价格可能偏离局部均值，均值回归机会可能增加 | 价格可能偏离局部均值，均值回归机会可能增加 |

因此，短期或中短期 RSI 进入超买区，不表示价格必然下跌；进入超卖区，也不表示价格必然上涨。

连续 RSI 通常比二元阈值特征保留更多信息。例如，RSI 从 69 升至 71 与从 71 升至 92，都可能处于超买状态，但极端程度和动量强度明显不同。因此，超买、超卖字段更适合作为研究或补充特征；是否作为训练输入应依样本外结果决定。

## 缺失值与零分母

### 起始值与预热期

当前实现将首日缺少的价格变化按零处理，并从序列开始递归平滑。因此，它不具有严格 Wilder RSI 需要 `period` 个价格变化的固定预热期。

如果序列开始阶段只有上涨或只有下跌，平滑后的下跌或上涨幅度可能为零，RSI 会相应出现 `100` 或 `0`；若上涨和下跌幅度均为零，则 RSI 为 `NaN`。这些序列起始值的稳定性较低，建模时应结合全量特征统一处理样本起始区间。

### 零分母

RSI 分母为：

$$
AvgGain_t + AvgLoss_t
$$

| `AvgGain` | `AvgLoss` | RSI 结果 | 含义                         |
| --------- | --------- | -------- | ---------------------------- |
| `> 0`     | `0`       | `100`    | 平滑区间内只有上涨幅度       |
| `0`       | `> 0`     | `0`      | 平滑区间内只有下跌幅度       |
| `0`       | `0`       | `NaN`    | 没有价格变化，强弱比例未定义 |

项目保留未定义的 `NaN`，而不强制填为 `50`。这避免将“完全静止、没有方向信息”伪装成“上涨与下跌幅度恰好平衡”。

## 验证建议

### 时间序列检查

建议将收盘价、`rsi_6`、`rsi_14` 与 30、50、70 水平线一起绘制，重点确认：

- RSI 是否始终位于 `0` 到 `100`；
- `RSI(6)` 是否比 `RSI(14)` 更快响应价格变化；
- 连续上涨或下跌时，RSI 是否接近对应极限；
- 平盘、单边上涨和单边下跌时，零分母结果是否符合预期；
- 与外部实现对比时，是否采用同一初始化口径。

### 样本外有效性

每天可按 `rsi_6`、`rsi_14` 或两者组合状态进行横截面分组，比较各组未来 1、5、20 日平均超额收益、Rank IC 及分年度表现。

还应按趋势和波动率状态分层，例如 DEMA spread 正负、Bollinger 带宽高低，以判断 RSI 的作用更接近趋势延续、均值回归，还是仅在特定市场环境中有效。

是否保留 `rsi_6`、`rsi_14` 及其阈值衍生特征，应以 walk-forward 样本外检验、特征重要度和 ablation test 为依据，而不是预先认定“超买必跌、超卖必涨”。

## 当前特征集合

默认 RSI 特征如下：

| 类别           | 特征                                     |
| -------------- | ---------------------------------------- |
| 连续动量状态   | `rsi_6`、`rsi_14`                        |
| 短期阈值状态   | `rsi_6_over_bought`、`rsi_6_over_sold`   |
| 中短期阈值状态 | `rsi_14_over_bought`、`rsi_14_over_sold` |

当前的 6 / 14 双周期设计同时提供短期敏感性与较平滑的经典 RSI 状态。后续若增加更多周期、变化率或历史分位数特征，应先验证其是否在样本外带来稳定增量，避免无差别扩充高度相关的技术指标。

## 常见解读与阈值

下表的区间与事件用于描述指标状态，是研究参照而非独立的交易指令。

| RSI 区间或事件 | 常见解读 |
| --- | --- |
| `RSI > 70` | 常被视为偏强或超买状态。 |
| `RSI < 30` | 常被视为偏弱或超卖状态。 |
| RSI 上升并突破中轴 | 动量可能转强。 |
| RSI 下降并跌破中轴 | 动量可能转弱。 |
| `30 ≤ RSI ≤ 70` | 通常处于非极端区，需更多关注 RSI 的方向和趋势背景。 |
| RSI 与价格走势背离 | 可作为动量减弱的研究线索，不能单独确认反转。 |

超买不等于价格必须下跌，超卖也不等于价格必须上涨；阈值应结合趋势验证。
