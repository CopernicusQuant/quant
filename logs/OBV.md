# OBV 特征设计

## 结论

当前实现以价格涨跌方向对成交量进行签名，并在 **5 / 20 日**窗口内计算归一化后的成交量流强度。它用于描述：

> 最近一段时间的成交量，更集中地发生在上涨日还是下跌日。

当前输出的不是传统定义中持续累加的 OBV 水平值，而是更适合作为跨股票比较和机器学习输入的**滚动、归一化方向性成交量流**。

| 特征                      | 时间尺度 | 含义                                          |
| ------------------------- | -------- | --------------------------------------------- |
| `obv_flow_strength_5`     | 短期     | 最近 5 日上涨/下跌日的净成交量占总成交量比例  |
| `obv_flow_strength_20`    | 中短期   | 最近 20 日上涨/下跌日的净成交量占总成交量比例 |
| `obv_strength_accel_5_20` | 快慢差   | 短期成交量流强度相对中短期强度的变化          |

---

## 指标定义

令复权收盘价为 $Close_t$，成交量为 $Volume_t$，每日价格变化为：

$$
\Delta_t = Close_t - Close_{t-1}
$$

根据当天收盘价变化，为成交量赋予方向：

$$
SignedVolume_t =
\begin{cases}
+Volume_t, & \Delta_t > 0 \\
-Volume_t, & \Delta_t < 0 \\
0, & \Delta_t = 0
\end{cases}
$$

因此：

- 收盘价上涨，当日成交量记为正；
- 收盘价下跌，当日成交量记为负；
- 收盘价不变，当日成交量不计入净方向流；
- 首日没有前一日收盘价可比较，当前实现将其 `SignedVolume` 设为 `0`。

对于长度为 $n$ 的滚动窗口，净方向成交量流为：

$$
Flow_{n,t} = \sum_{i=t-n+1}^{t} SignedVolume_i
$$

窗口总成交量为：

$$
TotalVolume_{n,t} = \sum_{i=t-n+1}^{t} Volume_i
$$

最终的成交量流强度定义为：

$$
Strength_{n,t} = \frac{Flow_{n,t}}{TotalVolume_{n,t}}
$$

项目计算：

$$
obv\_flow\_strength\_5 = Strength_5
$$

$$
obv\_flow\_strength\_20 = Strength_{20}
$$

## 与传统 OBV 的关系

传统 OBV（On-Balance Volume）通常定义为签名成交量的累计和：

$$
OBV_t = OBV_{t-1} + SignedVolume_t
$$

传统 OBV 会随历史长度和股票成交量规模持续累积，因此其绝对水平通常不适合直接在不同股票之间比较。

当前实现没有保留累计的 `OBV_t`，而是在固定窗口内使用：

$$
\frac{\sum SignedVolume}{\sum Volume}
$$

进行归一化。该设计有以下特点：

| 项目         | 传统累计 OBV           | 当前 `obv_flow_strength`                 |
| ------------ | ---------------------- | ---------------------------------------- |
| 计算方式     | 签名成交量的历史累计和 | 窗口签名成交量 / 窗口总成交量            |
| 取值范围     | 无固定范围             | 正常成交量非负且分母非零时位于 `[-1, 1]` |
| 历史依赖     | 依赖完整历史与初始值   | 仅依赖最近 `n` 日                        |
| 跨股票可比性 | 较弱，受成交量规模影响 | 较强，已按窗口成交量归一化               |
| 当前用途     | 未输出                 | 模型连续特征                     |

因此，`obv_flow_strength` 名称中的 “OBV” 表示其使用了 OBV 的涨跌方向成交量思想，但其统计口径更准确地说是**归一化滚动 signed-volume flow**。

## 5 / 20 双周期含义

当前使用 5 日和 20 日两个窗口：

| 特征                   | 解释                                                       |
| ---------------------- | ---------------------------------------------------------- |
| `obv_flow_strength_5`  | 最近约一周交易日内的方向性成交量状态，反应更快但噪声更大   |
| `obv_flow_strength_20` | 最近约一个月交易日内的方向性成交量状态，更平滑、更偏中短期 |

取值可以按下表理解：

| 强度值 | 含义                                                           |
| -----: | -------------------------------------------------------------- |
|   `+1` | 窗口内全部成交量发生在上涨日                                   |
|    `0` | 上涨日与下跌日的方向性成交量大致平衡，或成交量主要发生在平盘日 |
|   `-1` | 窗口内全部成交量发生在下跌日                                   |
|  `> 0` | 上涨日成交量占优                                               |
|  `< 0` | 下跌日成交量占优                                               |

例如，若 5 日内上涨日成交量合计为 80、下跌日成交量合计为 20，且没有平盘日成交量，则：

$$
Strength_5 = \frac{80 - 20}{80 + 20} = 0.6
$$

即最近 5 日的净方向成交量流为 `+60%`。

平盘日的成交量会进入分母、但不会进入分子。因此，成交量主要发生在价格不变日时，强度会向零收缩；这表示该窗口缺少明确的价格方向确认。

## 快慢强度差：`obv_strength_accel_5_20`

当前实现定义：

$$
obv\_strength\_accel\_{5\_20,t} = Strength_{5,t} - Strength_{20,t}
$$

它衡量最近 5 日的方向性成交量，是否相对最近 20 日显著增强或减弱。

| 状态        | 可能含义                                             |
| ----------- | ---------------------------------------------------- |
| `accel > 0` | 短期成交量流比中短期更偏向上涨日，或下跌压力正在减弱 |
| `accel < 0` | 短期成交量流比中短期更偏向下跌日，或上涨买盘正在减弱 |
| `accel ≈ 0` | 短期与中短期方向性成交量状态接近                     |

因为两个强度值各自位于 `[-1, 1]`，两者之差位于：

$$
[-2, 2]
$$

`accel` 的正负不等价于“价格必涨”或“价格必跌”。例如，在 20 日强度为 `-0.8`、5 日强度为 `-0.2` 时，`accel = +0.6`，其含义是短期卖压较长期明显减弱，但短期净方向成交量仍然为负。

## 缺失值与边界情况

### Warm-up period

滚动计算要求窗口完整：

| 特征                      | 首个可能有效的位置 |
| ------------------------- | ------------------ |
| `obv_flow_strength_5`     | 第 5 行            |
| `obv_flow_strength_20`    | 第 20 行           |
| `obv_strength_accel_5_20` | 第 20 行           |

在窗口未形成前，结果保持 `NaN`。不应将这些值填为 `0`，因为 `NaN` 表示历史数据不足，而 `0` 表示已形成窗口但买卖方向成交量恰好平衡或缺乏方向。

### 零成交量窗口

若一个完整窗口的总成交量为零：

$$
TotalVolume_{n,t} = 0
$$

强度的分母为零，pandas 除法结果会是 `NaN`。当前实现保留该未定义结果，不人为赋值。对日频股票数据而言，这通常意味着数据缺失、停牌或数据源口径需要检查。

### 缺失值

若 `adj_close` 或 `vol` 存在缺失值，价格方向或滚动求和会受影响，并可能导致后续特征为 `NaN`。训练、回测和线上推理应采用一致的缺失值处理规则。

## 特征使用建议

这三个字段均为连续变量，应优先保留连续值，而不是预先离散化为“资金流入/流出”或“金叉/死叉”标签。

| 特征                      | 建议角色                   |
| ------------------------- | -------------------------- |
| `obv_flow_strength_5`     | 短期成交量方向确认         |
| `obv_flow_strength_20`    | 中短期成交量方向状态       |
| `obv_strength_accel_5_20` | 短期相对中短期的方向流变化 |

它们与仅使用价格的 RSI、MACD、DEMA 等指标可能形成互补：价格指标描述价格本身的方向和动量，成交量流强度描述该方向在成交量层面是否获得确认。

但成交量特征不能单独证明买卖盘的真实资金流入或流出：日频数据只根据收盘价相对前收盘价为全部成交量赋予单一方向，无法观测日内逐笔成交方向。因此，应将其理解为**价格方向加权的成交量确认信号**，而不是严格的资金流向数据。

是否保留 5 日、20 日及其差值，应通过样本外 walk-forward、特征重要度和 ablation test 验证。特别建议按趋势、波动率、换手率或成交量异常状态分层检验，确认该特征在不同市场环境中的稳定性。

## 常见解读与阈值

下表的区间与事件用于描述指标状态，是研究参照而非独立的交易指令。

| OBV 强度状态或事件 | 常见解读 |
| --- | --- |
| `obv_flow_strength` 为正 | 近期净方向成交量偏向买方。 |
| `obv_flow_strength` 为负 | 近期净方向成交量偏向卖方。 |
| 短期强度高于长期强度 | 买卖力量可能正在增强。 |
| 短期强度低于长期强度 | 买卖力量可能正在减弱。 |
| 强度为正且持续上升 | 买方方向成交量的确认程度可能增强。 |
| 强度为负且持续下降 | 卖方方向成交量的确认程度可能增强。 |

成交量方向不直接决定价格走势，应结合价格趋势、流动性和市场状态验证。
